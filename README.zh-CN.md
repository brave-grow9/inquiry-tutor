# Inquiry Tutor · 问答式教学

**一个用「提问」而不是「讲解」带你进入新领域的 AI skill。**

*[English →](README.md)*

---

## 它解决什么问题

进一个新领域，最难的从来不是找不到资料，而是——

> **读的时候都懂，合上书什么都不记得。**

那不是「学会了」，那是「**看过了**」。

Inquiry Tutor 反过来做：**不解释给你听，而是问到你答得出来。**

---

## 怎么运作

```
        AI 先铺垫（给一个情境、一个例子、一段材料）
                        ↓
                AI 只问一个问题
                        ↓
                    你来回答
                        ↓
        ┌──────────────┬──────────────┬──────────────┐
        │   答对  →    │   答错  →    │   卡住  →    │
        │  确认、给术语 │  换个更基础的 │  退回去补铺垫 │
        │  加速推进     │  问法，不给答案│  别硬推       │
        └──────────────┴──────────────┴──────────────┘
                        ↓
                  … 循环若干轮 …
                        ↓
        整理成笔记 → 存到你指定的文件夹
```

**两条从不破例的规矩：**

1. **一次只问一个问题。** 绝不会一次抛一串。
2. **从不把答案直接给你。** 你答错了，它换一个更简单的问题问。

## 怎么用

直接说你想学什么就行：

```
带我学一点行为经济学，从零开始。
```

```
Teach me behavioral economics from scratch.
```

接下来它会先问你几个配置问题（具体想学什么、为了什么、现在的基础、一次学完还是分几次、笔记存哪、有没有想结合的资料），然后给你画一张领域地图，开始问答循环。

---

## 为什么这套方法有效

三条，都来自实际使用：

**① 它逼你暴露「以为自己懂了」**
读东西的时候人是会点头的。被提问的时候，你才知道自己到底懂没懂。**这是两回事。**

**② 你答错时，立刻知道错在哪**
它不说「你错了」，而是问一个更小的问题，**让你自己撞到那个错误**。
**自己撞到的错误，忘不掉。**

**③ 可以一直问，问到通为止**
换个问法再问一遍，来回绕。**不占用别人的时间。**

还有一件事它做到了，而大多数学习工具没做——**它会把你在哪里卡住过，写下来。**

---

## 会保存什么

每学完一轮，它会生成一份笔记，包含四块：

| | |
|---|---|
| **1. 这一轮学了什么** | 知识本身 |
| **2. 我是怎么绕过来的** | 你的推理路径——**你自己的原话，不作润色** |
| **3. 我在哪里卡住过** | 卡点，以及它为什么难 |
| **4. 自测题** | 方便你以后自己检验 |

**第 2、3 块才是重点。**
第 1 块任何教材都有，**第 2、3 块只属于你。**

笔记里还会记**进度**——这次没学完，下次把笔记递回去就能接着走。

## 可以结合你自己的资料

你可以指定一本书、一篇论文、一份文档或一个文件夹。三种模式：

| 模式 | 谁主导 | 资料的角色 |
|---|---|---|
| **A** | 教学方 | —— |
| **B** | **你的资料** | 整轮都围绕它推进 |
| **C** | 教学方 | 当参考，需要时取用 |

**资料不是牢笼。** 资料没覆盖的地方，它会补——**并且告诉你它在补**。资料和它说法冲突，你拿到的是**两边的说法**，不是被抹平的结论。

## 安全性

**这个 skill 不含任何脚本，也不发任何网络请求。**

它是一份纯文本指令。不执行代码、不读你没指给它的文件、不往任何地方发送数据。**安装前你可以逐行读完。**

---

## 什么时候不该用它

这是为「**学会一个领域**」设计的，不是为「**解决一个具体问题**」设计的。

- 你只要一个直接答案 → 直接问就行
- 你要一份摘要 → 直接要摘要
- 你说了「别问我，直接讲」→ 它会照做
